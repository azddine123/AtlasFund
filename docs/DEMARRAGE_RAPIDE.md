# À ouvrir en premier

1. Lire le rapport de 12 pages pour comprendre l’ensemble.
2. Suivre le README pour installer et lancer les quatre terminaux.
3. Lire les règles de déblocage anticipé et de remboursement avant les essais.
4. Rejouer les 26 tests Hardhat et les 5 tests Python.
5. Tester la connexion MetaMask avec un compte Hardhat de démonstration.
6. Utiliser SOUTENANCE_10_MIN.md pour expliquer et défendre les choix.

## Ce qui rend AtlasFund distinctif
- Un contexte étudiant concret et une interface cohérente.
- Un tableau réunissant état du séquestre, gouvernance et contrôle des retraits.
- Un bonus Python explicable, relié à des événements réellement émis.
- Une économie de jetons avec destruction au remboursement.
- Des preuves de tests adversariaux et un audit interprété avec limites.

## Ce qui n’est pas revendiqué
Pas de mise en production, de déploiement Sepolia, d’audit indépendant, de modèle ML entraîné ni de validation d’une véritable extension MetaMask dans les captures automatiques. Ces limites sont déclarées dans le rapport et le README.

## Personnalisation finale
Ajouter les noms et les travaux réels des coéquipiers, adapter les campagnes à des projets qui vous intéressent, et vérifier les règles de l’enseignant sur l’usage de l’IA. Le code et le script de génération du rapport sont modifiables.
